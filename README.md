# Employee Interview Analysis

一个面向 HRBP、组织发展和管理者的 Codex Skill：将员工访谈、焦点小组、留任访谈及员工声音材料，转化为有证据边界的组织诊断和管理决策建议。

当前版本：**2.0.0**

## 核心能力

- 提取可观察现象，避免在现象中偷渡归因；
- 建立议题树、竞争性假设和证据验证矩阵；
- 用组织诊断六盒框架检查机制与跨盒不一致；
- 区分员工证据、分析解释、归因假设和管理诊断；
- 输出管理待决事项、行动选项、验证信号和员工反馈闭环。

## 适用与边界

适用于批量员工访谈、焦点小组、一对一记录、留任访谈和员工声音材料的分析、比较与管理层汇报。

不用于候选人录用面试、个人绩效评价、违纪或法律事实调查、心理诊断，以及没有员工证据的纯访谈提纲设计。

## 安装

克隆到 Codex Skills 目录：

```bash
git clone <YOUR_REPOSITORY_URL> ~/.codex/skills/employee-interview-analysis
```

或者下载 Release ZIP，并解压为：

```text
~/.codex/skills/employee-interview-analysis/
```

确认该目录下直接存在 `SKILL.md`，不要再次嵌套同名目录。

## 使用

```text
使用 $employee-interview-analysis 分析这批员工访谈，
提取关键现象，建立竞争性归因假设，
并输出六盒组织诊断、管理待决事项和验证闭环。
```

建议同时提供管理决策、访谈对象、样本量、收集周期、匿名化记录、分组字段、保密限制和目标读者。信息不完整时 Skill 仍会继续分析，但会明确证据限制。

## 典型输出

1. 决策问题与证据边界；
2. 管理结论与待决事项；
3. 优先风险和关键现象；
4. 六盒诊断与跨盒不一致；
5. 竞争性归因及验证矩阵；
6. 行动选项、证伪条件和员工反馈闭环。

## 隐私与安全

- 上传前删除姓名、工号、精确岗位和可识别的独特事件；
- 不要把真实访谈、访问 Token 或公司机密提交到公开仓库；
- 员工感知是员工体验的证据，不等于对事件或责任归属的核实事实；
- 本 Skill 不能替代正式调查、法律意见、医疗建议或危机处置；
- 严重风险应交由有权限的专业渠道处理。
