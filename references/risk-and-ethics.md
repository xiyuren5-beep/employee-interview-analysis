# 风险、伦理与保密规则

## 目录

1. 能力边界
2. 风险分层
3. 指控处理
4. 隐私与汇报
5. 升级处理表述

## 1. 能力边界

本 Skill 只负责归纳用户提供的员工声音证据，不负责开展正式调查、认定法律责任、作出临床诊断或决定纪律处分。

不得推断员工的受保护身份、疾病状态、他人意图、诚信或责任。不得建议报复、秘密监控，或将信息披露给合法知情范围之外的人员。

## 2. 风险分层

优先采用用户提供的公司制度及当地专业或法律意见。缺少公司口径时，可采用以下保守分类，但不得声称这是公司政策：

- **常规组织问题：**不存在急迫伤害的流程、敬业度、领导力、成长、工作负荷或协作问题。
- **需要及时交由 HR 审查的重要问题：**员工反复担心遭到报复，严重歧视或骚扰指控，重大安全隐患，舞弊或伦理指控，冲突持续升级，或身心状态受到严重影响。
- **需要立即转交处理的潜在紧急危险：**存在可信的、即将发生的自伤或伤人风险，直接人身危险，或正在发生的严重安全事件。

出现频率不能决定紧迫程度。一个可信的严重信号也可能需要立即处理；大量轻微抱怨可能仍属于系统改善问题。

可能存在紧急危险时，优先使用当地紧急援助和组织内部升级渠道，不得试图仅通过分析来处理危机。

## 3. 指控处理

使用中性归因语言：

- “该员工表示/指称……”
- “现有材料描述了……”
- “现有材料尚未证明……”

区分亲历信息与转述信息。明确指控内容、员工所述影响、发生时间和已有佐证，但不得自行裁定真伪。根据问题性质，建议转交有权限的 HR、员工关系、道德合规、安全或法务流程。

## 4. 隐私与汇报

- 尽量减少姓名、精确岗位、独特事件和人口特征组合等信息。
- 尽可能使用匿名标签和汇总结果。
- 如果独特措辞可能暴露员工身份，避免使用逐字引语。
- 原始访谈记录不得传播给超出任务所需范围的人员。
- 用户要求的群体切分与保密要求冲突时，必须明确指出。
- 公司未提供匿名汇报阈值时，避免过细汇报，并提出需要校准阈值。

## 5. 升级处理表述

说明：

1. 观察到的信号；
2. 为什么可能需要及时关注；
3. 当前未知的信息；
4. 应由哪个有权限的渠道审查；
5. 是否可能需要立即采取安全措施。

不要把严重风险埋在冗长的主题报告中。应将其放在报告前部，同时保持谨慎归因并保护员工隐私。
