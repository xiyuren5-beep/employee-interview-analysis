## 1. 证据模型

严格区分四个层次：

- **直接证据：**员工明确表达的内容，或原始记录明确显示的事实。
- **模式：**多个证据单元中重复出现或存在重要关联的现象。
- **分析解释：**分析者对证据可能含义的判断。
- **假设：**对于模式成因或未来影响的、可以进一步验证的解释。

使用与证据强度相匹配的语言：

- 直接证据：“P03 提到……”“5 份访谈中有 2 份描述了……”
- 分析解释：“这可能说明……”“一种合理解释是……”
- 证据不足：“现有材料无法证明……”“这一点仍需验证……”

员工感知是员工体验的真实证据，但不能自动当作对事件、他人动机、制度执行或责任归属的已核实事实。

## 2. 分析单位与编码

一个证据单元只承载一个相对完整的观点或经历，同时保留足够语境，防止原意被扭曲。

优先采用描述性初级编码，例如：

- 晋升标准不清晰；
- 主管反馈响应慢；
- 高负荷后缺少恢复时间；
- 同事支持增强留任意愿；
- 战略背景信息提升工作动力。

避免过早使用“文化差”“有毒领导”等评价性标签。先描述信号，再进行判断。

建议使用以下编码记录：

| 字段 | 含义 |
|---|---|
| 来源 | 匿名员工或访谈标签 |
| 证据 | 简短转述或原话 |
| 描述性编码 | 证据表达了什么 |
| 倾向 | 积极、消极、复杂或中性 |
| 强度 | 根据措辞和影响评为低、中、高 |
| 语境 | 团队、司龄、事件、流程或时间 |
| 分析备注 | 与原始证据分开的分析解释 |

## 3. 主题构建

主题应表达有意义的共同机制，而不仅是宽泛的话题分类。

较弱的主题：“沟通”。

更强的主题：“决策背景传递过晚且不一致，造成了可避免的返工。”

每个主题都要检验：

- 一致性：证据单元是否描述同一机制；
- 区分度：是否与其他主题存在实质区别；
- 完整性：是否包含相关反例与差异；
- 决策价值：是否有助于采取行动或开展后续验证。

不要把相反意见模糊地平均化。员工体验存在实质分化时，应如实呈现分化。

## 4. 覆盖度、强度与置信度

把三个维度分开判断。

### 覆盖度

分母已知时，按不同员工或访谈报告为 `n/N`。不能把便利抽样转换为总体百分比。样本量未知或很小时，使用“一名员工”“多份访谈”或“在现有材料中重复出现”等有边界的表述。

### 强度

依据员工表达的后果和紧迫性判断，而不是依据字数或提及次数：

- **低：**偏好、轻度摩擦或影响有限的单次不便。
- **中：**反复受挫、工作效能受损、信任下降或开始考虑改变。
- **高：**严重伤害、紧急安全或伦理问题、严重失灵，或员工明确表示即将采取重大行动。

### 置信度

- **高：**存在多个相互独立且具体的例子，语境清晰，实质性反向证据较少。
- **中：**存在可信的重复信号，但语境不完整、样本有限或有部分矛盾。
- **低：**意见孤立或含糊、来源不明、属于转述，或存在大量冲突证据。

置信度表示对“现有材料内这项发现”的把握程度，不代表统计显著性或组织总体代表性。

## 5. 根因推理

建立以下推理链：

`员工体验 → 直接作用机制 → 促成条件 → 系统性假设`

例如：

`员工报告返工 → 执行开始后决策才到达 → 决策权责不清 → 治理节奏可能与交付节奏不匹配`

检验替代解释。不得仅凭员工情绪推断他人意图、人格、临床状态、受保护身份相关因果关系或违规事实。说明还需要什么证据才能区分不同假设。

## 6. 群体分层

只有在有助于决策且能够保护匿名性时才进行分层。可考虑岗位族、司龄区间、地点、管理层级或访谈轮次。

如果切分结果可能让人推断出具体员工，就不要发布。不要擅自设定统一的最小样本阈值，应优先使用公司的隐私规则。公司未提供规则时，避免过细切分，并标记需要补充汇报阈值。

## 7. 行动设计

每项行动都要对应证据所揭示的机制：

| 周期 | 目的 | 典型形式 |
|---|---|---|
| 即时 | 保护人员或稳定紧急风险 | 转交、控制、确认安全、保存证据 |
| 近期 | 消除反复出现的运营摩擦 | 明确负责人、调整节奏、闭环反馈 |
| 长期 | 改变持续产生问题的系统 | 重设治理、激励、管理能力或制度 |

每项行动明确：

- 针对的发现；
- 行动与负责人；
- 目标时间；
- 员工反馈闭环；
- 过程信号与结果信号；
- 潜在副作用。

避免“加强沟通”这类空泛建议，除非明确渠道、负责人、对象、时点以及期望改变的行为。
